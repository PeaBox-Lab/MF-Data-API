Why MF Data API

Everything you need, nothing you don't

A deliberately small API surface, predictable JSON, and data that stays fresh without any maintenance on your side.

⚡

Fast by design

Indexed SQLite queries, gzip compression and short-lived cache headers keep responses quick even for full histories.

🔓

Completely free

No authentication, no API keys and no registration. Use it from a notebook, a side project or a production dashboard.

📊

Complete data

Scheme name, AMC, type, category, ISINs and the full daily NAV history — all in one response.

🔄

Automatic daily updates

A scheduled GitHub Actions workflow pulls the official AMFI feed, rebuilds the database and publishes new JSON.

🧩

Easy integration

Plain REST + JSON works with Python, JavaScript, Excel, Google Sheets, R, Go — anything that can make an HTTP request.

🛡️

Self-hostable

Run the whole stack with Docker, or publish the generated static JSON tree to any CDN or GitHub Pages.

Transparent pipeline

From AMFI's feed to your app

The repository contains the full ingestion workflow, so you can audit exactly where every number comes from.

Download official data

The pipeline fetches NAVAll.txt plus historical reports from AMFI India, in 30-day chunks with retries.

Normalise & store

Rows are parsed, de-duplicated and upserted into SQLite. Scheme metadata is merged across feeds and kept current.

Publish APIs

FastAPI serves live queries, while the same payloads are exported as static JSON for free hosting and offline use.

API surface

Four endpoints cover most use cases

All endpoints are GET, return JSON, and accept an optional /api/v1 prefix.

EndpointWhat it returnsExample
GET /mf Every scheme code and name, with optional pagination and filters. Reference
GET /mf/search?q= Case-insensitive scheme search ranked by prefix matches. Reference
GET /mf/{code} Metadata and full NAV history, newest first, with date filtering. Reference
GET /mf/{code}/latest The single most recent NAV for one scheme. Reference

Additional endpoints: all latest NAVs, scheme metadata, fund houses, categories, NAVs by date and dataset stats.
