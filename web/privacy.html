Privacy policy

Last updated: 21 November 2026

MF Data API is a read-only public data service. This policy explains the very small amount of information the service processes when you use it.

What we collect

  • Request metadata: the live API keeps short-lived, in-memory counters keyed by client IP address solely to enforce rate limits. These counters expire automatically and are not written to disk.
  • Server logs: the hosting platform may record standard request logs (IP address, timestamp, path, user agent) for security and operations.
  • No accounts: the API does not offer registration, cookies, advertising or analytics tracking.

What we do not collect

We do not sell, rent or share personal information. We do not use third-party advertising or cross-site tracking scripts on this documentation site.

Data you request

API responses contain public mutual fund information published by AMFI India. They do not contain personal data.

Third-party links

This site links to AMFI India and other external resources. Their privacy practices are governed by their own policies.

Self-hosted deployments

If you deploy this project yourself, you control the hosting environment, logs and any additional analytics you choose to add. The bundled code does not include analytics.

Contact

For privacy questions, open an issue in the project repository. This project is not affiliated with AMFI, SEBI or any asset management company.
