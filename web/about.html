About MF Data API

Free Indian mutual fund data for everyone

MF Data API provides programmatic access to Indian mutual fund Net Asset Values (NAVs), scheme metadata, and historical data — completely free, no registration required.

What is MF Data API?

MF Data API is a free, open-source JSON API that provides complete historical NAV data for all Indian mutual fund schemes. The data is sourced directly from AMFI India (Association of Mutual Funds in India), the official industry body for mutual funds in India.

It mirrors the popular mfapi.in service but is fully self-hostable, transparent, and includes additional endpoints for fund houses, categories, and bulk access.

Key features

  • Complete coverage: ~14,000+ schemes across 55+ fund houses
  • Historical depth: Multi-year NAV history with daily granularity
  • Rich metadata: Scheme type, category, plan, option, ISINs
  • No authentication: Open API, no keys, no signup, no rate-limit surprises
  • Daily updates: Automated GitHub Actions workflow refreshes data twice daily from AMFI
  • Dual mode: Run as a live FastAPI service or deploy as static JSON to GitHub Pages/CDN
  • Self-hostable: Docker image, Python package, or static export — you own your deployment
  • Developer friendly: REST + JSON, Swagger UI, interactive explorer, code examples

Data pipeline transparency

Unlike black-box APIs, the entire ingestion pipeline is open source and runs in GitHub Actions:

  1. Downloads NAVAll.txt (latest NAVs) and DownloadNAVHistoryReport_Po.aspx (historical) from AMFI
  2. Parses, normalises, and de-duplicates rows into SQLite with WAL mode
  3. Refreshes denormalised "latest NAV" columns and computes dataset statistics
  4. Exports the full API as static JSON files (one per scheme) for zero-server hosting
  5. Commits dataset status and deploys the documentation site to GitHub Pages

You can audit every step in the pipeline/ directory and run it yourself locally or on your own infrastructure.

Use cases

Portfolio tracking

Fetch latest NAVs for your holdings to calculate real-time portfolio value.

Historical analysis

Download full NAV history for backtesting, performance charts, or risk analysis.

Financial apps

Embed NAV data in personal finance apps, robo-advisors, or research dashboards.

Spreadsheets

Use IMPORTDATA in Google Sheets or Power Query in Excel for no-code access.

Academic research

Clean, structured dataset for mutual fund performance studies and market analysis.

Automation

Schedule daily NAV pulls for compliance reporting, client statements, or alerts.
