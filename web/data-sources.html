API Access Methods

The API explorer lets you try all endpoints directly from your browser. For each API endpoint, you can:

  • Try live endpoints: Access the live API through the explorer (or directly through the API URL)
  • Try static endpoints: Access static JSON files (e.g., /api/v1/data-sources.json)
  • Copy API URLs: Copy endpoint URLs directly from the explorer
  • Search and filter: Use the search box to find specific APIs or sources
  • View documentation: Click on the "Docs" link in each API card for detailed information

All APIs provide JSON responses with the same consistent format. The explorer automatically detects static mode and adapts to local file access.

Getting Started

To explore the APIs:

  1. Search for an API using the search box or browse the table above
  2. Click on an API card to see its details and try the API explorer
  3. Use the API explorer to make requests directly from your browser
  4. Copy API URLs to use in your own applications

All APIs are free to access with no registration required. Some APIs have rate limits — be respectful and check the rate limit information for each API.
